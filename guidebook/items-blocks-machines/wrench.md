# Wrench

<Row>
  <ItemImage id="create:wrench" scale="4" />
</Row>

A Wrench can be used to rotate TL2 devices (right-click), and disassemble TL2 blocks (shift-right-click).
Subparts can be removed from a cable without breaking everything on the cable
(or the cable can be removed without breaking the subparts.)

Many TL2 blocks can be rotated, so just because this guide doesn't say you can rotate something doesn't mean you can't.
